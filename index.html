CAVITY 2

Control valve cavitation, surge and noise analysis

This repository contains a lightweight installable web app shell for the CAVITY 2 project, including manifest metadata and an offline-capable service worker.

Purpose

The app provides screening and design tools for assessing cavitation, surge, and noise in control valves.

Method

Uses the CAVITY approach based on the cavitation index σ = (Pd + Pb − Pva)/(Pu − Pd) with valve pressure terms.

Installation

Host the files on a web address and install the app from a browser to use it offline on supported devices.
